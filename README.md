# ❤️ A Comparitive study of modern Optmization Algorithms on Heart Disease Prediction

## 📌 Project Overview
This project presents a comprehensive comparative study of multiple optimization algorithms applied to heart disease prediction. The goal is to analyze how different optimization techniques influence machine learning model performance, convergence behavior, and prediction accuracy.

Heart disease is one of the leading causes of death worldwide, making early detection extremely important. This project uses Logistic Regression models trained with several optimization algorithms to predict heart disease risk.

---

## 🎯 Project Objectives
- Implement and compare optimization algorithms
- Train Logistic Regression models using different optimizers
- Analyze convergence and performance
- Verify optimality conditions (KKT & LICQ)
- Visualize optimization trajectories and cost functions
- Evaluate prediction accuracy on medical data

---

## 📊 Dataset
This project uses the **Heart Disease UCI Dataset** containing patient medical records.

### Features Used
- Age
- Sex
- Chest Pain Type (cp)
- Resting Blood Pressure (trestbps)
- Serum Cholesterol (chol)
- Fasting Blood Sugar (fbs)
- Resting ECG (restecg)
- Maximum Heart Rate (thalach)
- Exercise Induced Angina (exang)
- ST Depression (oldpeak)

Dataset Source:
https://www.kaggle.com/code/mragpavank/heart-disease-uci/notebook
